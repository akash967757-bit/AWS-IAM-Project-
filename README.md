# AWS IAM Project

## Project Overview

This project demonstrates Identity and Access Management (IAM)
in Amazon Web Services (AWS).

The project focuses on creating IAM users, groups, and policies
to manage access to AWS resources securely.

## AWS Service Used

## Project Implementation

### 1. IAM Users

Created IAM users for different access requirements.

Example:

- Developer User
- Admin User

### 2. IAM Groups

Created groups to manage permissions efficiently.

Example:

- Developers
- Administrators

### 3. IAM Policies

Attached appropriate IAM policies to users/groups based on
their required permissions.

### 4. Access Management

Configured permissions following the principle of least privilege.

## Key Concepts Learned

- IAM Users
- IAM Groups
- IAM Policies
- Permissions
- Least Privilege
- Authentication
- Authorization
- AWS Console Access

## Project Outcome

Learned how AWS IAM can be used to securely manage identities,
users, groups, and permissions within an AWS environment.
